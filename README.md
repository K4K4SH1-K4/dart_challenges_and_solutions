# Dart Apprentice: Real-World Engineering Challenges 🚀

A practical Dart programming challenge series based on the concepts covered in _Dart Apprentice: Fundamentals_ by Jonathan Sande.

The goal of this project is to move beyond memorizing Dart syntax and develop the ability to apply programming concepts to real-world problems through structured problem-solving, logical reasoning, validation, and object-oriented design.

## 🎯 Objectives

- Strengthen my understanding of Dart fundamentals through practical implementation.
- Learn when, where, and how to use variables, constants, data types, operators, strings, control flow, loops, functions, and classes.
- Develop solutions to realistic business and operational problems.
- Improve code readability, correctness, validation, and program structure.
- Learn to identify and handle edge cases.
- Build confidence in designing software solutions independently.

## 📚 Concepts Covered

- Dart fundamentals and development environment setup
- Expressions, variables, and constants
- Types and operations
- Strings and string interpolation
- Control flow and conditional logic
- Loops
- Functions and parameters
- Classes and object-oriented programming fundamentals

## 🛠️ Technology Stack

## 🧩 Challenges

### Challenge 01: Small Business Sales & Profit Intelligence System

**Focus:** Revenue calculations, discounts, gross profit, profit margins, validation, functions, and classes.

Develop a console application that calculates business sales performance and determines whether a business is making a profit, breaking even, or operating at a loss.

### Challenge 02: Farm Operations & Investment Decision Engine

**Focus:** Crop investment analysis, expected yield, revenue, production costs, return on investment (ROI), and scenario analysis.

Develop a system that evaluates crop investment proposals and estimates their financial performance under different market conditions.

### Challenge 03: Mobile Money Transaction Risk Simulator

**Focus:** Transaction validation, transfer fees, account balances, transaction limits, conditional logic, and state management.

Develop a simplified mobile money transaction simulator that approves or rejects transfers according to defined business rules.

### Challenge 04: Student Academic Performance & Progress Analyzer

**Focus:** Weighted marks, grade boundaries, validation, conditional logic, and reporting.

Develop a system that calculates academic performance and generates meaningful reports based on assessment results.

### Challenge 05: Inventory Reorder & Stockout Prevention System

**Focus:** Stock management, reorder thresholds, procurement costs, budget validation, and inventory calculations.

Develop a system that monitors stock levels, recommends replenishment, and identifies potential stockouts or budget shortfalls.

### Challenge 06: Business Operations Simulator — Capstone

**Focus:** Integration, object-oriented design, transaction processing, financial calculations, validation, and reporting.

Combine the concepts from the previous challenges into a console-based business management simulator.

## 🧪 Development Approach

For each challenge, I aim to:

1. Analyze the problem and identify its requirements.
2. Define the assumptions and business rules.
3. Identify the required classes, variables, and functions.
4. Implement the solution using the Dart concepts already covered.
5. Test normal scenarios and edge cases.
6. Review the code for correctness, readability, and maintainability.
7. Document the lessons learned and improvements made.

## 📏 Learning Constraints

This project focuses on the Dart chapters I have completed so far.

I will avoid relying on advanced language features or external technologies that I have not studied yet. Each solution should demonstrate my understanding of the fundamentals rather than simply produce the correct output.
